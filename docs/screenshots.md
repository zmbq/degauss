# Screenshots

The READMEs use these images from `docs/images/`. Take them with
[`docs/demo/phosphor.py`](demo/phosphor.py) open, so every look shows all of its colors, and crop to the
window, about 1400–1600 pixels wide, so the pixel fonts stay legible.

| File | What to capture | Used on |
|---|---|---|
| `hero.png` | VS Code with **Apple //e in amber**: `phosphor.py` plus the built-in terminal | Both READMEs, top |
| `apple2e-green.png` | Apple //e in green, same file | Extension page, looks |
| `ibm-3270.png` | **IBM 3270** in color, to show the ISPF highlighting | Extension page, looks |
| `ibm-3270-mono.png` | IBM 3270 Monochrome, green | Extension page, looks |
| `choose-look.png` | The **Degauss: Choose Look…** list open | Extension page, getting started |
| `phosphor-colors.png` | The phosphor color list (Green, Amber, White…) open | Extension page, phosphor colors |
| `windows-terminal.png` | Windows Terminal with an Apple //e and an IBM PS/2 tab (`look apple`, `look ps2`), running `python docs/demo/phosphor.py` and `Get-DegaussLook` | Root README, Windows Terminal |

Before saving, check for personal details: host names in remote windows, user names in paths, other
projects' files in the Explorer or tabs, email addresses in Git blame or chat panels.
