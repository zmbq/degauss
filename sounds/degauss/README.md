# The degauss sound

`degauss.wav` is cut from a recording of a real CRT monitor degaussing:

- **Recording:** [Computer CRT monitor turn on/off/degauss](https://freesound.org/people/Sanderboah/sounds/838728/)
  by Sanderboah, on Freesound: an early-2000s Compaq PC monitor turning on, degaussing and turning off.
- **License:** [Creative Commons 0 (CC0 1.0 Universal)](https://creativecommons.org/publicdomain/zero/1.0/),
  public domain dedication. No attribution is required; we credit the recordist anyway, with Freesound's
  attribution text: "Computer CRT monitor turn on/off/degauss by Sanderboah -- https://freesound.org/s/838728/ --
  License: Creative Commons 0".
- **Edits:** the 2 seconds from 12.355 s (the relay's thunk, then the coil's hum), resampled from 96 kHz to
  48 kHz (16-bit mono), with a 2 ms fade-in and a 300 ms fade-out, peak-normalized to -1 dBFS.

The build copies it into both products unchanged.
